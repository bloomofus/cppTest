    一、数组篇

    27. 移除元素

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给你一个数组 nums 和一个值 val，你需要原地移除所有数值等于 val 的元素，并返回移除后数组的新长度。

    不要使用额外的数组空间，你必须仅使用 O(1) 额外空间并原地修改输入数组。

    元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

    示例输入输出
    示例 1nums = [3,2,2,3], val = 3返回 2，nums 前两个元素为 2
    示例 2nums = [0,1,2,2,3,0,4,2], val = 2返回 5，nums 前五个元素为 0, 1, 3, 0, 4

    提示：

    • 0 <= nums.length <= 100
    • 0 <= nums[i] <= 50
    • 0 <= val <= 100

    解题思路

    快慢指针：slow 指向下一个可覆盖的位置，fast 负责遍历寻找非 val 的元素。当 nums[fast] != val 时，把它复制到 slow 处并 slow++。一趟遍历即完成原地覆盖，避免每次删除都移动后续元素（erase 的 O(n²) 开销）。

    复杂度分析

    时间 O(n)，空间 O(1)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        int slow = 0;                        // slow 指向下一个可覆盖位置
        for (int fast = 0; fast < nums.size(); ++fast) {
            if (nums[fast] != val) {         // fast 找非 val 元素
                nums[slow++] = nums[fast];   // 覆盖到 slow 处
            }
        }
        return slow;
    }
};

    二、字符串篇

    344. 反转字符串

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    编写一个函数，其作用是将输入的字符串反转过来。输入字符串以字符数组 s 的形式给出。

    不要给另外的数组分配额外的空间，你必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

    示例输入输出
    示例 1s = ["h","e","l","l","o"]["o","l","l","e","h"]
    示例 2s = ["H","a","n","n","a","h"]["h","a","n","n","a","H"]

    提示：

    • 1 <= s.length <= 10^5
    • s[i] 都是 ASCII 码表中的可打印字符

    解题思路

    左右双指针：left 指向开头、right 指向末尾，交换 s[left] 与 s[right] 后向中间靠拢，直到 left >= right。原地交换，无需额外空间。

    复杂度分析

    时间 O(n)，空间 O(1)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0;
        int right = s.size() - 1;
        while (left < right) {
            swap(s[left], s[right]);
            ++left;
            --right;
        }
    }
};

    剑指 Offer 05. 替换空格

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 无公开课视频

    题目描述

    请实现一个函数，把字符串 s 中的每个空格替换成 %20（LeetCode 原题）。

    代码随想录题解页当前为卡码网版本：把字符串中的数字字符替换为 number，思路完全一致，代码见下方版本提示。

    示例输入输出
    示例 1s = "We are happy.""We%20are%20happy."

    提示：

    • 0 <= s 的长度 <= 10000

    解题思路

    先统计空格个数 count，把字符串扩容为 oldSize + 2*count；然后从后向前双指针填充：i 指向旧串末尾、j 指向新串末尾，字母直接赋值，遇到空格从后往前依次填入 0、2、%。从后向前填充可避免每次插入都后移后续元素（O(n²) 开销）。

    复杂度分析

    时间 O(n)，空间 O(1)（原地扩容）

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    string replaceSpace(string s) {
        int count = 0;                         // 统计空格个数
        for (char c : s) {
            if (c == ' ') ++count;
        }
        int oldSize = s.size();
        s.resize(oldSize + 2 * count);         // 每个空格多占 2 个字符
        // 从后向前双指针填充：i 指旧末尾，j 指新末尾
        for (int i = oldSize - 1, j = s.size() - 1; i >= 0; --i, --j) {
            if (s[i] != ' ') {
                s[j] = s[i];
            } else {
                s[j] = '0';
                s[j - 1] = '2';
                s[j - 2] = '%';
                j -= 2;
            }
        }
        return s;
    }
};
    📌 版本提示
    📌 卡码网版本（数字 → number）只需把「统计空格」改为「统计数字字符」，填充时改为依次填入 r、e、b、m、u、n，其余结构不变。

    151. 翻转字符串里的单词

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给你一个字符串 s，请你反转字符串中单词的顺序。

    单词是由非空格字符组成的字符串。s 中使用至少一个空格将字符串中的单词分隔开。

    返回单词顺序颠倒且单词之间用单个空格连接的结果字符串。

    注意：输入字符串 s 中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

    示例输入输出
    示例 1s = "the sky is blue""blue is sky the"
    示例 2s = " hello world ""world hello"
    示例 3s = "a good example""example good a"

    提示：

    • 1 <= s.length <= 10^4
    • s 包含英文大小写字母、数字和空格 ' '
    • s 中至少存在一个单词

    解题思路

    三步走：① 用快慢指针原地移除多余空格（前导、尾随、连续空格只保留一个）；② 反转整个字符串；③ 以空格为边界，逐个反转每个单词。三步均在 O(1) 空间内完成。

    复杂度分析

    时间 O(n)，空间 O(1)（原地）

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    // 反转区间 [left, right]
    void reverse(string& s, int left, int right) {
        while (left < right) {
            swap(s[left], s[right]);
            ++left;
            --right;
        }
    }

    string reverseWords(string s) {
        // 1. 双指针原地移除多余空格（前导、尾随、连续空格）
        int slow = 0;
        for (int fast = 0; fast < s.size(); ++fast) {
            if (s[fast] != ' ') {
                if (slow != 0) s[slow++] = ' ';      // 单词之间补一个空格
                while (fast < s.size() && s[fast] != ' ') {
                    s[slow++] = s[fast++];           // 复制整个单词
                }
            }
        }
        s.resize(slow);
        // 2. 反转整个字符串
        reverse(s, 0, s.size() - 1);
        // 3. 以空格为边界，逐个反转单词
        int start = 0;
        for (int i = 0; i <= s.size(); ++i) {
            if (i == s.size() || s[i] == ' ') {
                reverse(s, start, i - 1);
                start = i + 1;
            }
        }
        return s;
    }
};

    三、链表篇

    206. 反转链表

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给你单链表的头节点 head，请你反转链表，并返回反转后的链表。

    示例输入输出
    示例 1head = [1,2,3,4,5][5,4,3,2,1]
    示例 2head = [1,2][2,1]
    示例 3head = [][]

    提示：

    • 链表中节点数目范围 [0, 5000]
    • -5000 <= Node.val <= 5000
    • 进阶：链表可以选用迭代或递归方式完成反转，你能否用两种方法解决？

    解题思路

    双指针迭代：pre 初始为 nullptr，cur 指向 head。每次先用 tmp 保存 cur->next（防止断链丢失），令 cur->next = pre 反转指向，然后 pre、cur 各前进一步。cur 为空时 pre 即反转后的新头节点。

    复杂度分析

    时间 O(n)，空间 O(1)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;     // 前一个节点
        ListNode* cur = head;        // 当前节点
        while (cur != nullptr) {
            ListNode* tmp = cur->next;  // 保存后继，防止断链
            cur->next = pre;            // 反转指向
            pre = cur;
            cur = tmp;
        }
        return pre;                  // pre 即反转后的头节点
    }
};

    19. 删除链表的倒数第 N 个节点

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。

    进阶：你能尝试使用一趟扫描实现吗？

    示例输入输出
    示例 1head = [1,2,3,4,5], n = 2[1,2,3,5]
    示例 2head = [1], n = 1[]
    示例 3head = [1,2], n = 1[1]

    提示：

    • 链表中节点数目为 sz
    • 1 <= sz <= 30
    • 0 <= Node.val <= 100
    • 1 <= n <= sz

    解题思路

    虚拟头节点 + 快慢指针：fast 先走 n+1 步，然后 fast、slow 同步每次走一步；fast 走到链表末尾（nullptr）时，slow 正好指向待删节点的前一个节点，执行 slow->next = slow->next->next 完成删除，一趟扫描实现。

    复杂度分析

    时间 O(n)，空间 O(1)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummyHead = new ListNode(0, head);  // 虚拟头节点
        ListNode* fast = dummyHead;
        ListNode* slow = dummyHead;
        ++n;                                         // fast 先走 n+1 步
        while (n-- > 0 && fast != nullptr) {
            fast = fast->next;
        }
        while (fast != nullptr) {                    // 快慢同步移动
            fast = fast->next;
            slow = slow->next;
        }
        slow->next = slow->next->next;               // 删除倒数第 n 个节点
        return dummyHead->next;
    }
};

    面试题 02.07. 链表相交（同 160）

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 无公开课视频

    题目描述

    给你两个单链表的头节点 headA 和 headB，请你找出并返回两个单链表相交的起始节点。如果两个链表没有交点，返回 null。

    题目数据保证整个链式结构中不存在环。注意，函数返回结果后，链表必须保持其原始结构。

    示例输入输出
    示例 1intersectVal = 8, listA = [4,1,8,4,5], listB = [5,0,1,8,4,5]相交节点 &#39;8&#39;
    示例 2intersectVal = 2, listA = [0,9,1,2,4], listB = [3,2,4]相交节点 &#39;2&#39;
    示例 3intersectVal = 0, listA = [2,6,4], listB = [1,5]null（不相交）

    提示：

    • listA 节点数为 m，listB 节点数为 n，0 <= m, n <= 3*10^4
    • 1 <= Node.val <= 10^5；0 <= skipA <= m，0 <= skipB <= n
    • 进阶：设计一个时间复杂度 O(m+n)、仅用 O(1) 内存的解决方案

    解题思路

    先分别遍历两个链表求长度；让较长的链表指针先走长度差 gap，使两个指针尾部对齐；然后同步移动，比较的是节点指针而非节点值，第一个相等的指针就是交点；若走到末尾仍无相等，返回 null。

    复杂度分析

    时间 O(m+n)，空间 O(1)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        // 1. 求两链表长度
        ListNode* curA = headA;
        ListNode* curB = headB;
        int lenA = 0, lenB = 0;
        while (curA) { ++lenA; curA = curA->next; }
        while (curB) { ++lenB; curB = curB->next; }
        // 2. 让 curA 指向较长的链表
        curA = headA;
        curB = headB;
        if (lenA < lenB) {
            swap(lenA, lenB);
            swap(curA, curB);
        }
        // 3. 长链表先走差值，使尾部对齐
        int gap = lenA - lenB;
        while (gap--) curA = curA->next;
        // 4. 同步移动，比较节点指针
        while (curA != nullptr) {
            if (curA == curB) return curA;
            curA = curA->next;
            curB = curB->next;
        }
        return nullptr;
    }
};

    142. 环形链表 II

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给定一个链表的头节点 head，返回链表开始入环的第一个节点。如果链表无环，则返回 null。

    如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 pos 是 -1，则在该链表中没有环。注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。

    不允许修改给定的链表。

    示例输入输出
    示例 1head = [3,2,0,-4], pos = 1返回索引为 1 的链表节点
    示例 2head = [1,2], pos = 0返回索引为 0 的链表节点
    示例 3head = [1], pos = -1返回 null

    提示：

    • 链表中节点数目范围 [0, 10^4]
    • -10^5 <= Node.val <= 10^5
    • pos 的值为 -1 或链表中的一个有效索引
    • 进阶：你是否可以使用 O(1) 空间解决此题？

    解题思路

    快慢指针：fast 每次走 2 步、slow 每次走 1 步。若有环，两者必然相遇（每轮追近 1 步）。设头节点到环入口距离为 x、环入口到相遇点距离为 y、环剩余长度为 z，由路程关系 2(x+y) = x+y+n(y+z) 推出 x = (n-1)(y+z) + z：把一个指针放回头节点、另一个留在相遇点，各自每次走 1 步，再次相遇处就是环入口。

    复杂度分析

    时间 O(n)，空间 O(1)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* fast = head;
        ListNode* slow = head;
        // 快慢指针：fast 走 2 步，slow 走 1 步
        while (fast != nullptr && fast->next != nullptr) {
            fast = fast->next->next;
            slow = slow->next;
            if (fast == slow) {                 // 相遇说明有环
                ListNode* index1 = fast;        // 一个留在相遇点
                ListNode* index2 = head;        // 一个回到头节点
                while (index1 != index2) {      // 各走 1 步，相遇处即环入口
                    index1 = index1->next;
                    index2 = index2->next;
                }
                return index1;
            }
        }
        return nullptr;
    }
};

    15. 三数之和

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给你一个整数数组 nums，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k，同时还满足 nums[i] + nums[j] + nums[k] == 0。请你返回所有和为 0 且不重复的三元组。

    注意：答案中不可以包含重复的三元组。

    示例输入输出
    示例 1nums = [-1,0,1,2,-1,-4][[-1,-1,2],[-1,0,1]]
    示例 2nums = [0,1,1][]
    示例 3nums = [0,0,0][[0,0,0]]

    提示：

    • 3 <= nums.length <= 3000
    • -10^5 <= nums[i] <= 10^5

    解题思路

    排序 + 双指针：先对数组升序排序。固定 i 作为 a（去重：与 nums[i-1] 比较），用 left = i+1、right = n-1 双指针找 b、c：sum > 0 时 right--；sum < 0 时 left++；sum == 0 记录结果，并对 b、c 去重后同时收缩。剪枝：nums[i] > 0 时直接结束（升序数组后面和必大于 0）。注意 a 的去重必须比较 nums[i] 与 nums[i-1]，若比较后一位会漏掉 {-1,-1,2} 这类答案。

    复杂度分析

    时间 O(n²)，空间 O(1)（不含排序与结果存储）

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());
        for (int i = 0; i < nums.size(); ++i) {
            if (nums[i] > 0) break;                        // 剪枝：首元素 > 0，三数之和必 > 0
            if (i > 0 && nums[i] == nums[i - 1]) continue; // a 去重
            int left = i + 1;
            int right = nums.size() - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum > 0) {
                    --right;
                } else if (sum < 0) {
                    ++left;
                } else {
                    result.push_back({nums[i], nums[left], nums[right]});
                    while (left < right && nums[left] == nums[left + 1]) ++left;    // b 去重
                    while (left < right && nums[right] == nums[right - 1]) --right; // c 去重
                    ++left;
                    --right;
                }
            }
        }
        return result;
    }
};

    18. 四数之和

    题目描述

    给你一个由 n 个整数组成的数组 nums，和一个目标值 target。请你找出并返回满足下述全部条件且不重复的四元组 [nums[a], nums[b], nums[c], nums[d]]（若两个四元组元素一一对应，则认为两个四元组重复）：

    • 0 <= a, b, c, d < n
    • a、b、c 和 d 互不相同
    • nums[a] + nums[b] + nums[c] + nums[d] == target
    你可以按任意顺序返回答案。

    示例输入输出
    示例 1nums = [1,0,-1,0,-2,2], target = 0[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
    示例 2nums = [2,2,2,2,2], target = 8[[2,2,2,2]]

    提示：

    • 1 <= nums.length <= 200
    • -10^9 <= nums[i] <= 10^9
    • -10^9 <= target <= 10^9

    解题思路

    排序 + 双指针：在 i、j 两层循环固定前两个数（各自去重、剪枝），再用 left/right 双指针找后两个数，比三数之和多一层循环。注意：target 可为负，剪枝需同时满足 nums[i] > target 且 nums[i] >= 0；求和用 long 防溢出（数值范围 ±10^9）。

    复杂度分析

    时间 O(n³)，空间 O(1)（不含排序与结果存储）

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());
        for (int i = 0; i < nums.size(); ++i) {
            // 剪枝：target 可为负，必须同时满足 nums[i] >= 0
            if (nums[i] > target && nums[i] >= 0) break;
            if (i > 0 && nums[i] == nums[i - 1]) continue;       // a 去重
            for (int j = i + 1; j < nums.size(); ++j) {
                if (nums[i] + nums[j] > target && nums[i] + nums[j] >= 0) break;  // 剪枝
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;                // b 去重
                int left = j + 1;
                int right = nums.size() - 1;
                while (left < right) {
                    // 用 long 防溢出（数值范围 ±10^9）
                    long sum = (long)nums[i] + nums[j] + nums[left] + nums[right];
                    if (sum > target) {
                        --right;
                    } else if (sum < target) {
                        ++left;
                    } else {
                        result.push_back({nums[i], nums[j], nums[left], nums[right]});
                        while (left < right && nums[left] == nums[left + 1]) ++left;    // c 去重
                        while (left < right && nums[right] == nums[right - 1]) --right; // d 去重
                        ++left;
                        --right;
                    }
                }
            }
        }
        return result;
    }
};
