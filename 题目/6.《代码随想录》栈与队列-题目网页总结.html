    232. 用栈实现队列

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    请你仅使用两个栈实现先入先出队列。队列应当支持一般队列支持的所有操作（push、pop、peek、empty）：push(x) —— 将元素 x 推到队列的末尾；pop() —— 从队列的开头移除并返回元素；peek() —— 返回队列开头的元素；empty() —— 如果队列为空，返回 true；否则，返回 false。

    说明：你只能使用标准的栈操作 —— 也就是只有 push to top、peek/pop from top、size 和 is empty 操作是合法的。你所使用的语言也许不支持栈。你可以使用 list 或者 deque（双端队列）来模拟一个栈，只要是标准的栈操作即可。假设所有操作都是有效的（例如，一个空的队列不会调用 pop 或者 peek 操作）。

    进阶：你能否实现每个操作均摊时间复杂度为 O(1) 的队列？换句话说，执行 n 个操作的总时间复杂度为 O(n)，即使其中一个操作可能花费较长时间。

    示例输入输出
    示例 1输入：["MyQueue", "push", "push", "peek", "pop", "empty"]，[[], [1], [2], [], [], []]输出：[null, null, null, 1, 1, false]
    示例 1 解释MyQueue myQueue = new MyQueue(); myQueue.push(1); myQueue.push(2); myQueue.peek(); // 返回 1；myQueue.pop(); // 返回 1；myQueue.empty(); // 返回 false说明：peek() 返回队首元素 1，pop() 返回 1，empty() 返回 false

    提示：

    • 只能使用标准的栈操作：push to top、peek/pop from top、size 和 is empty
    • 假设所有操作都是有效的（例如，一个空的队列不会调用 pop 或者 peek 操作）
    • 1 <= x <= 9，最多调用 100 次 push、pop、peek 和 empty
    • 进阶：能否实现每个操作均摊时间复杂度为 O(1) 的队列

    解题思路

    用两个栈模拟队列：一个输入栈负责 push，一个输出栈负责 pop 与 peek。push(x) 将元素压入输入栈；pop() 时若输出栈为空，则把输入栈元素全部弹出并压入输出栈（顺序被反转，队列头变为输出栈栈顶），再从输出栈弹出；输出栈非空则直接弹出。peek() 复用 pop() 逻辑取出队首元素后将其放回输出栈。empty() 判断两个栈是否同时为空。核心思想：栈是后进先出，元素经过两个栈两次反转后恢复先进先出的顺序。

    复杂度分析

    时间复杂度：push/pop/peek/empty 均为 O(1)（pop/peek 均摊 O(1)），空间复杂度 O(n)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class MyQueue {
public:
    stack<int> stIn;    // 输入栈
    stack<int> stOut;   // 输出栈
    MyQueue() {}

    void push(int x) {
        stIn.push(x);
    }

    int pop() {
        // 输出栈为空时，把输入栈全部倒入输出栈（负负得正，顺序复原）
        if (stOut.empty()) {
            while (!stIn.empty()) {
                stOut.push(stIn.top());
                stIn.pop();
            }
        }
        int res = stOut.top();
        stOut.pop();
        return res;
    }

    int peek() {
        int res = this->pop();  // 复用 pop 逻辑
        stOut.push(res);        // 弹出去的元素再加回来
        return res;
    }

    bool empty() {
        return stIn.empty() && stOut.empty();
    }
};

    225. 用队列实现栈

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    请你仅使用两个队列实现一个后入先出（LIFO）的栈，并支持普通栈的全部四种操作（push、top、pop 和 empty）。实现 MyStack 类：void push(int x) 将元素 x 压入栈顶；int pop() 移除并返回栈顶元素；int top() 返回栈顶元素；boolean empty() 如果栈是空的，返回 true；否则，返回 false。

    注意：你只能使用队列的基本操作 —— 也就是 push to back、peek/pop from front、size 和 is empty 这些操作。你所使用的语言也许不支持队列。你可以使用 list 或者 deque（双端队列）来模拟一个队列，只要是标准的队列操作即可。

    进阶：你能否仅用一个队列来实现栈？

    示例输入输出
    示例 1输入：["MyStack", "push", "push", "top", "pop", "empty"]，[[], [1], [2], [], [], []]输出：[null, null, null, 2, 2, false]
    示例 1 解释MyStack myStack = new MyStack(); myStack.push(1); myStack.push(2); myStack.top(); // 返回 2；myStack.pop(); // 返回 2；myStack.empty(); // 返回 false说明：top() 返回栈顶元素 2，pop() 返回 2，empty() 返回 false

    提示：

    • 只能使用队列的基本操作：push to back、peek/pop from front、size 和 is empty
    • 每次调用 pop 和 top 都保证栈不为空
    • 1 <= x <= 9，最多调用 100 次 push、pop、top 和 empty
    • 进阶：能否仅用一个队列实现栈

    解题思路

    用队列模拟栈（可只用单队列，也可用双队列）。单队列做法：push(x) 直接入队；pop() 时把队列前 n-1 个元素依次出队并入队尾，剩下的队首元素即栈顶，出队即可；top() 同样把前 n-1 个元素移到队尾后读取队首，再把该元素放回队尾。双队列做法：用备份队列辅助，pop/top 时先把主队列除最后一个元素外全部暂存到备份队列，处理完再倒回。本质是利用队列先进先出的特性，通过移动元素改变出队顺序以模拟后进先出。

    复杂度分析

    时间复杂度：push 与 empty 为 O(1)，pop 与 top 为 O(n)，空间复杂度 O(n)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class MyStack {
public:
    queue<int> que;
    MyStack() {}

    void push(int x) {
        que.push(x);
    }

    int pop() {
        // 把队尾以外的元素全部搬到队尾之后，队头即栈顶
        int size = que.size() - 1;
        while (size--) {
            que.push(que.front());
            que.pop();
        }
        int res = que.front();
        que.pop();
        return res;
    }

    int top() {
        return que.back();
    }

    bool empty() {
        return que.empty();
    }
};

    二、栈经典题目

    20. 有效的括号

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s，判断字符串是否有效。

    有效字符串需满足：左括号必须用相同类型的右括号闭合；左括号必须以正确的顺序闭合；每个右括号都有一个对应的相同类型的左括号。

    注意：空字符串可被认为是有效字符串。

    示例输入输出
    示例 1输入: s = "()"输出: true
    示例 2输入: s = "()[]{}"输出: true
    示例 3输入: s = "(]"输出: false
    示例 4输入: s = "([)]"输出: false
    示例 5输入: s = "{[]}"输出: true

    提示：

    • 1 <= s.length <= 10^4
    • s 仅由括号 '()[]{}' 组成

    解题思路

    括号匹配是使用栈解决的经典问题，栈的对称特性非常适合匹配类题目。遍历字符串：遇到左括号时，把对应的右括号入栈（技巧：入栈右括号，比较时只需判断当前字符与栈顶是否相等）；遇到右括号时与栈顶比较，不匹配则无效。需要覆盖三种不匹配情况：左括号多余（遍历完栈不空）、括号类型不匹配（栈顶与当前右括号不同）、右括号多余（栈已空）。剪枝：字符串长度为奇数可直接返回 false。遍历结束后栈为空则字符串有效。

    复杂度分析

    时间复杂度 O(n)，空间复杂度 O(n)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    bool isValid(string s) {
        stack<char> st;
        for (char c : s) {
            if (c == '(') st.push(')');
            else if (c == '[') st.push(']');
            else if (c == '{') st.push('}');
            else {                       // 右括号：与栈顶匹配
                if (st.empty() || st.top() != c) return false;
                st.pop();
            }
        }
        return st.empty();
    }
};

    1047. 删除字符串中的所有相邻重复项

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给出由小写字母组成的字符串 S，重复项删除操作会选择两个相邻且相同的字母，并删除它们。

    在 S 上反复执行重复项删除操作，直到无法继续删除。在完成所有重复项删除操作后返回最终的字符串。答案保证唯一。

    示例输入输出
    示例 1输入: "abbaca"输出: "ca"
    示例 1 解释在 "abbaca" 中，我们可以删除 "bb"，得到字符串 "aaca"；其中又只有 "aa" 可以执行重复项删除操作，所以最后的字符串为 "ca"删除反复进行直到无法继续删除
    示例 2输入: "s"输出: "s"

    提示：

    • 1 <= S.length <= 20000
    • S 仅由小写英文字母组成

    解题思路

    思路与括号匹配类似，是字符串的"对对碰"。遍历字符串，用栈保存结果：当前字符与栈顶相同时，弹出栈顶（消除一对相邻重复）；不同则将该字符入栈。遍历结束后，栈中剩余字符依次弹出即为最终字符串（注意弹出顺序是反的，需反转；也可直接用字符串模拟栈，从尾部比较与删除，省去反转）。题目保证答案唯一，删除操作反复进行直到无法继续删除。

    复杂度分析

    时间复杂度 O(n)，空间复杂度 O(n)（用字符串模拟栈时不计返回值的空间为 O(1)）

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    string removeDuplicates(string s) {
        string res;                      // 用字符串模拟栈
        for (char c : s) {
            if (!res.empty() && res.back() == c) {
                res.pop_back();          // 相邻重复：弹出
            } else {
                res.push_back(c);
            }
        }
        return res;
    }
};

    150. 逆波兰表达式求值

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    根据 逆波兰表示法，求表达式的值。有效的运算符包括 +、-、*、/ 。每个运算对象可以是整数，也可以是另一个逆波兰表达式。

    说明：整数除法只保留整数部分。给定逆波兰表达式总是有效的。换句话说，表达式总会得出有效数值且不存在除数为 0 的情况。

    逆波兰表达式是一种后缀表达式，所谓后缀就是指运算符写在后面。平常使用的算式则是一种中缀表达式，如 ( 1 + 2 ) * ( 3 + 4 ) 。该算式的逆波兰表达式写法为 ( ( 1 2 + ) ( 3 4 + ) * ) 。逆波兰表达式主要有以下两个优点：去掉括号后表达式无歧义，上式即便写成 1 2 + 3 4 + * 也可以依据次序计算出正确结果；适合用栈操作运算：遇到数字则入栈，遇到算符则取出栈顶两个数字进行计算，并将结果压入栈中。

    示例输入输出
    示例 1输入: tokens = ["2","1","+","3","*"]输出: 9
    示例 1 解释该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9计算结果为 9
    示例 2输入: tokens = ["4","13","5","/","+"]输出: 6
    示例 2 解释该算式转化为常见的中缀算术表达式为：(4 + (13 / 5)) = 6计算结果为 6
    示例 3输入: tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]输出: 22
    示例 3 解释该算式转化为常见的中缀算术表达式为：((10 * (6 / ((9 + 3) * -11))) + 17) + 5计算结果为 22

    提示：

    • 整数除法只保留整数部分（向零截断）
    • 给定逆波兰表达式总是有效的：表达式总会得出有效数值且不存在除数为 0 的情况
    • 1 <= tokens.length <= 10^4；tokens[i] 是运算符（"+"、"-"、"*" 或 "/"）或范围 [-200, 200] 内的一个整数

    解题思路

    逆波兰表达式（后缀表达式）是二叉树后序遍历的序列化形式，去掉括号后无歧义，计算机可用栈顺序处理，无需考虑运算符优先级与回退。遍历 tokens：遇到数字则入栈；遇到运算符时，弹出栈顶两个数字（先弹出的是右操作数），执行运算后将结果压回栈中。遍历结束后，栈顶即为表达式结果。注意：除法向零截断（整数除法只保留整数部分），题目保证表达式总是有效且不存在除数为 0 的情况，中间结果注意数据范围。

    复杂度分析

    时间复杂度 O(n)，空间复杂度 O(n)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<long long> st;
        for (string& t : tokens) {
            if (t == "+" || t == "-" || t == "*" || t == "/") {
                long long b = st.top(); st.pop();
                long long a = st.top(); st.pop();
                if (t == "+") st.push(a + b);
                else if (t == "-") st.push(a - b);
                else if (t == "*") st.push(a * b);
                else st.push(a / b);
            } else {
                st.push(stoll(t));
            }
        }
        return (int)st.top();
    }
};

    239. 滑动窗口最大值

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

    返回 滑动窗口中的最大值 。

    进阶：你能在线性时间复杂度内解决此题吗？

    示例输入输出
    示例 1输入: nums = [1,3,-1,-3,5,3,6,7], k = 3输出: [3,3,5,5,6,7]
    示例 1 解释滑动窗口位置依次为：1 [3 -1 -3] 5 3 6 7 → 3；1 3 [-1 -3 5] 3 6 7 → 5；1 3 -1 [-3 5 3] 6 7 → 5；1 3 -1 -3 [5 3 6] 7 → 6；1 3 -1 -3 5 [3 6 7] → 7输出 [3,3,5,5,6,7]
    示例 2输入: nums = [1], k = 1输出: [1]

    提示：

    • 1 <= nums.length <= 10^5
    • -10^4 <= nums[i] <= 10^4
    • 1 <= k <= nums.length
    • 进阶：能否在线性时间复杂度内解决此题

    解题思路

    本题不能用大顶堆（堆顶元素可能已滑出窗口）。解法是自定义单调递减队列（底层用 deque）：push(value) 时从队尾弹出所有小于 value 的元素后入队，保证队列内从大到小；pop(value) 仅在 value 等于队首时才弹出队首（对应窗口滑出的元素）。窗口每次滑动时，先 push 新元素，再 pop 滑出窗口的元素，此时队首即为当前窗口最大值。每个元素最多入队出队各一次，总复杂度 O(n)，达到线性时间要求。

    复杂度分析

    时间复杂度 O(n)，空间复杂度 O(k)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        // 单调队列（存下标）：队头到队尾单调递减，队头即窗口最大值
        deque<int> dq;
        vector<int> result;
        for (int i = 0; i < nums.size(); ++i) {
            // 1. 弹出滑出窗口的队头
            if (!dq.empty() && dq.front() < i - k + 1) dq.pop_front();
            // 2. 保持单调递减：弹出队尾所有不大于当前值的
            while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
            dq.push_back(i);
            // 3. 窗口成型后，队头即最大值
            if (i >= k - 1) result.push_back(nums[dq.front()]);
        }
        return result;
    }
};

    347. 前 K 个高频元素

    🔗 LeetCode 题目页 ｜ 📖 代码随想录题解 ｜ 🎬 B 站公开课

    题目描述

    给你一个整数数组 nums 和一个整数 k ，请你返回其中出现频率前 k 高的元素。你可以按 任意顺序 返回答案。

    进阶：你所设计算法的时间复杂度 必须 优于 O(n log n) ，其中 n 是数组大小。

    示例输入输出
    示例 1输入: nums = [1,1,1,2,2,3], k = 2输出: [1,2]
    示例 2输入: nums = [1], k = 1输出: [1]

    提示：

    • 1 <= nums.length <= 10^5
    • k 的取值范围是 [1, 数组中不相同的元素的个数]
    • 题目数据保证答案唯一，换句话说，数组中前 k 个高频元素的集合是唯一的
    • 算法的时间复杂度必须优于 O(n log n)，其中 n 是数组大小；可以按任意顺序返回答案

    解题思路

    分两步完成：先用哈希表统计每个元素出现的频率；再用大小为 k 的小顶堆（优先级队列，按频率排序）筛选前 k 高。遍历频率表，将元素入堆，当堆大小超过 k 时弹出堆顶（频率最小者），保证堆中始终保留当前出现频率最高的 k 个元素。选小顶堆而非大顶堆的原因：小顶堆每次弹出最小频率元素，最后留下的才是频率最大的前 k 个；大顶堆会先把最大值弹出，无法保留结果。最后从堆中倒序取出元素即为答案。

    复杂度分析

    时间复杂度 O(n log k)，空间复杂度 O(n)

    LeetCode 核心代码（C++）

    class Solution 核心代码模式
    class Solution {
public:
    // 小顶堆：堆顶是最小频率，保持堆大小为 k，堆内即前 k 个高频元素
    class mycomparison {
    public:
        bool operator()(const pair<int, int>& lhs, const pair<int, int>& rhs) {
            return lhs.second > rhs.second;
        }
    };
    vector<int> topKFrequent(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        for (int n : nums) ++freq[n];
        priority_queue<pair<int, int>, vector<pair<int, int>>, mycomparison> pq;
        for (auto& it : freq) {
            pq.push(it);
            if (pq.size() > k) pq.pop();   // 超过 k 个时弹出最小频率
        }
        vector<int> result;
        while (!pq.empty()) {
            result.push_back(pq.top().first);
            pq.pop();
        }
        return result;
    }
};
